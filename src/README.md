## 本书的一些符号和标注
- `<XXX>` 表示命令里你需要根据实际情况替换的内容.
例如你要[clone](git/workflow.md#克隆) `team-training`仓库，`git clone <url>`，你需要替换成`git clone git@github.com:mechanical-ancestor/team-training.git`.
